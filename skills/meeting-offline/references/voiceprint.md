# 本机声纹：只提供待确认的名字

默认关闭。首次使用必须先向用户说明：“声纹属于生物特征，只存在这台设备，用来建议说话人的名字；可随时按人删除，或关闭并删除全部声纹。”得到明确同意后，才执行：

```
python3 scripts/voiceprint.py enable --user-consented --install-dependencies
```

该命令记录同意时间，按需从 PyPI 安装可选的 `sherpa-onnx`，复用 `transcribe_local.py` 的 `EMBEDDING_URL` 和 `model_file()` 下载官方模型。`--user-consented` 是执行者传递已取得用户同意的凭据，不能由 AI 自行推断。单独 `enable --user-consented` 只记录偏好，不安装；未就绪时会报告缺失而不偷偷下载。基础功能和单元测试无需安装第三方库。云端沙箱 `MEETING_OFFLINE_SANDBOX=1` 始终禁用声纹。

## 使用与存储

- `status`：查看同意及可用性。
- `match --workspace W`：用本机原始录音计算并比对，仅预填名字，保持 `role_confirmed: false`、`role_source: voice_match`。自动识别的结果不能写入长期库或声纹库。
- `forget --profile ID`：删除这个已确认角色档案的全部声纹。
- `off`：关闭，并删除全部声纹（删除不可恢复，执行前确认用户明确要求删除）（不删除长期角色档案或用户原始录音）。模型本身不含用户声纹，可以保留。

声纹库是 `device_context.paths()['data_root']/voiceprints.json`，与 `memory.json` 分离、设备校验、文件锁加原子替换、私有临时文件。每条记录关联已由用户确认且仍有效的角色档案 ID、会议、说话人、确认时间。角色必须带 `confirmed_by_user: true` 和确认说明；仅有一段确认文字的旧条目不作为授权。旧档案仅在本次确实改变所选人物、原本未确认，或用户逐卡勾选明确确认时，才补记用户确认并允许登记；仅重发已确认卡片、保存其他卡片不会升级旧档案。API 的逐卡明确确认字段为 `confirm_identity: true`。旧档案字段不完整时明确报告校验错误，不自动修补或确认其他历史人物。多个确认样本以归一化向量的算术和更新中心；同一会议同一声音片段重复确认不重复加权。只有复核保存、明确的对话确认、网页修改导回这些用户确认入口调用登记。角色撤销后不再参与匹配；要彻底删除生物特征请 `forget` / `off`。

无论阿里云还是本地转写，均使用工作区 source 的本机 `audio_path`，不下载云端音频、不新增上传、无额外网络调用。模型下载仅发生在经同意的安装命令。计算没有网络请求。一次比对或登记批次只初始化一次模型，每份原始录音只计算一次哈希、解码一次。缺少 ffmpeg 或 PCM WAV 不支持时给出本机修复提示，保留代号。没有已确认角色时不提取声纹；库损坏或设备归属不符时保留原文件、返回降级原因，不阻断基础工作区创建。已记录原始录音 SHA256 时先核对文件，录音被替换则拒绝计算。未压缩整数 PCM WAV 的 8/16/24/32 位、多声道和不同采样率由标准库在本机解码：声道取平均、线性重采样为 16 kHz，再按原录音时间段提取。线性重采样不是高保真抗混叠滤波，异相声道平均可能削弱语音，需在实际设备录音上评估；不支持的压缩 WAV 应先本机转换。其他格式复用已安装的本机 ffmpeg 转码，未安装或格式不可用时跳过并说明，保留代号。

身份改派或撤回时，仅撤回本次真正改变的说话人贡献。库 JSON 损坏、设备或模型不符时保留原文件，允许保存身份并显示降级及修复提示，不登记新声纹。库可读但旧贡献无法安全撤回，或库文件写入失败时，不保存本次身份修改；请先备份并检查磁盘空间、写权限及库格式，再重试。关闭并清除旧库属于不可恢复删除，必须经用户明确授权，程序不会自动清除。

## 可靠片段与保守匹配

从说话人时间段中减去同一来源所有其他说话人（含未分离发言）的重叠区间；合并重复区间，不重复累计时长。留下的每个连续片段至少 2 秒，合计至少 10 秒，每人最多取 60 秒。无法确定时间、音频缺失或超长时间戳均不猜测。`<来源>-UNASSIGNED` 永远不计算、匹配或登记声纹，即使后续用户确认了其中身份也不拿混合片段训练库。

候选必须同时满足余弦相似度严格大于 0.80，且领先第二名至少 0.10；没有第二人时只应用首个门槛。按每份录音的 `source_id` 独立比对。同一份录音每个档案最多匹配一个说话人；两个说话人都强匹配同一档案时，两者都保持不确定，不贪心选最高分，也不退而求其次。已用户确认的身份只在该录音内占位，同一人可在另一份录音里再次识别。差距比较允许 1e-9 浮点容差。

0.80 / 0.10 是偏保守的初始工程值，不是准确率、置信概率或经真实用户录音校准的界限。多人音色接近、麦克风变化、噪声、短发言、转写分离错误都会导致拒识或误识；不能用于认证、考勤或自动确认身份。真实录音部署前应本机评估同人/异人样本，在保持低误识的前提下调整常量。

## 交付与确认

已确认身份、待确认自动名字、代号均可生成纪要；HTML 保留待确认标记，PNG 去掉标记。内容核对问题依旧阻止 publish 和归档，用户改正或确认后才放行。例外：沙箱或开启声纹仍无一人匹配时，仍走既有用户确认引导，先交付观点卡片，确认后才交付完整纪要 HTML / Todo。普通本机场景关闭声纹，或开启后至少一人匹配时，可直接生成完整纪要。用户未触碰的自动名字不会借“保存网页”自动进入长期库，只有明确确认/编辑过的映射才导回。

技能包不含声纹库、录音、会议内容或模型。测试仅使用合成向量和生成的 PCM WAV，提取器使用替身；本次实现不声称已通过真实录音、真实 Mac 麦克风/模型推理验证。
